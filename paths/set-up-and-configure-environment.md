# Learning path: Set up and Configure an Azure Databricks Environment

## What it is about

This path builds a foundation in Azure Databricks. It covers:

- creating workspaces and the core workloads
- how the control plane and compute plane are separated
- how Azure Databricks works with Microsoft Fabric, Power BI, Visual Studio Code, and other Microsoft services
- how to choose and configure compute for performance and cost
- how Unity Catalog organizes data assets

Source: [Learning path page](https://learn.microsoft.com/en-us/training/paths/azure-databricks-data-engineer-set-up-configure-environment/)

## Prerequisites

- Basic knowledge of data analytics concepts
- Basic understanding of cloud storage
- Familiarity with SQL and data organization

Estimated duration is not stated on the page.
