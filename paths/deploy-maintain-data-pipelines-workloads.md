# Learning path: Deploy and Maintain Data Pipelines and Workloads with Azure Databricks

## What it is about

This path covers the lifecycle of production data pipelines in Azure Databricks, from design and orchestration to monitoring and optimization. It covers:

- designing pipelines with notebooks and Lakeflow pipelines, including error handling
- orchestrating work with Lakeflow Jobs
- development lifecycle processes, such as version control and deployment
- monitoring, troubleshooting, and optimizing workloads

Source: [Learning path page](https://learn.microsoft.com/en-us/training/paths/azure-databricks-data-engineer-deploy-maintain-data-pipelines-workloads/)

## Prerequisites

- Good understanding of Azure Databricks workspaces
- Familiarity with data engineering concepts and SQL
- Experience with Python programming and notebooks
- Knowledge of Git version control fundamentals
