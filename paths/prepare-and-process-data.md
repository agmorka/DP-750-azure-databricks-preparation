# Learning path: Prepare and Process Data with Azure Databricks

## What it is about

This path builds a data engineering workflow with Azure Databricks and Unity Catalog. It covers:

- data modeling: schemas, partitioning, table formats, slowly changing dimensions, granularity, and clustering
- ingestion: managed connectors, notebooks, SQL loads, change data capture, streaming, Auto Loader, and Lakeflow pipelines
- transformation: data profiling, column types, duplicates and nulls, filters, joins, pivots, and load patterns
- data quality: validation checks, schema enforcement, schema drift, and pipeline expectations

Source: [Learning path page](https://learn.microsoft.com/en-us/training/paths/azure-databricks-data-engineer-prepare-process-data/)

## Prerequisites

- Good understanding of Azure Databricks workspaces and Unity Catalog
- Familiarity with SQL and Python
- Knowledge of data engineering and data warehouse concepts

Estimated duration is not stated on the page.
