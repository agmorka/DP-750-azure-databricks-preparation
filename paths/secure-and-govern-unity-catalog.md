# Learning path: Secure and Govern Unity Catalog Objects in Azure Databricks

## What it is about

This path covers how to secure and govern data in Unity Catalog. It covers:

- table and schema permissions, row filtering, and column masking
- managing credentials with Azure Key Vault, service principals, and managed identities
- governance tools: lineage, audit logging, and attribute-based access control
- sharing data with external parties using Delta Sharing

Source: [Learning path page](https://learn.microsoft.com/en-us/training/paths/azure-databricks-data-engineer-secure-govern-unity-catalog/)

## Prerequisites

- Good understanding of Azure Databricks workspaces and Unity Catalog
- Familiarity with SQL and data access patterns
- Knowledge of Microsoft Entra ID and Azure security basics

Estimated duration is not stated on the page.
